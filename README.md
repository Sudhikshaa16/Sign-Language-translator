# Bidirectional Real-Time Sign Language Translation System

A real-time bidirectional sign language translation system designed to improve communication accessibility.

## Features

- Sign-to-Text translation using MediaPipe hand landmarks and LSTM
- Text-to-Sign gesture display
- Real-time webcam-based recognition
- Custom dataset collected using webcam
- Machine learning-based gesture classification

## Technologies

- Python
- OpenCV
- MediaPipe
- PyTorch
- LSTM
- Streamlit
